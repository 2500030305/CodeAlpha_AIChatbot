# CodeAlpha AI Chatbot

## Description
This project is a simple rule-based AI Chatbot developed in Java as part of the CodeAlpha Java Internship.

The chatbot can interact with users and respond to different questions using conditional logic and string matching.

## Features
- Interactive chatbot
- Rule-based responses
- User-friendly console interaction
- Multiple predefined responses
- Continuous conversation support

## Technologies Used
- Java
- Conditional Statements
- Loops
- String Handling
- Scanner Class

## How to Run

Compile:
javac AIChatbot.java

Run:
java AIChatbot

## Sample Output
You: hello
Bot: Hello! Welcome to the chatbot.

You: java
Bot: Java is a powerful object-oriented programming language.
